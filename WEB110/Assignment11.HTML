Graphics and Multimedia Summary

Jakub Tomaszewski:

Computer graphics are pictures and films created using computers, while multimedia is content that combines different forms such as text, audio, images, animations, video, and interactive content. In this topic, I learned how to add existing graphics and multimedia to web pages and how to create and use simple graphic images and multimedia files.

I learned that there are two main types of graphics. Raster graphics, such as GIF, JPEG, and PNG files, are made up of pixels, while vector graphics, such as SVG files, are built from mathematical shapes. Knowing the difference helps me choose the right type for a web page.

I also learned how a web graphics project works from start to finish. First, I need to determine the client's requirements by reading and interpreting the client brief and analysing what they need in terms of image content, quality, and size. Next, I need to source the images by researching appropriate places to find them, while taking copyright restrictions into consideration so that I only use images I am allowed to use.

After that, I learned how to manipulate the images. This means selecting industry-standard image-editing software that suits the purpose, creating backups of the original assets before working on them, and using the software's features to create effects that suit the client's needs and the web application. I also learned how to edit, resize, and slice images so they work properly on a website. Finally, I learned to save the images in a way that maintains their individual effects.

The topic also introduced web multimedia, including audio and video content that can be added to web pages.

Overall, I learned that working with graphics and multimedia is about more than just editing images. It involves understanding what a client wants, using images legally, protecting original files, choosing the right file type, and preparing images so they look good and work well on a website.
