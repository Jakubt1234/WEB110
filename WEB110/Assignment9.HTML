What I Learned: Internet Fundamentals / HTML

I learned that HTML is the standard markup language for building web pages and web applications. It's the foundation of everything you see online, and this lesson did a good job of introducing it without overcomplicating things.

What stood out most is that the lesson treats HTML as a process, not just a list of tags. You start by reviewing the requirements: what the page needs to do, which markup language fits the organization's standards, and how the document should be structured. I think that's smart, because planning first saves a lot of trouble later.

Next comes building the structure. You create the basic elements of the document and mark up each section so the layout makes sense. The image on the page shows this as nested tags like <html> and <body>, which helped me picture how a page is organized from the top down.

The last step is validation. You check that the markup matches the requirements and that it works in different browsers. I hadn't thought much about this before, but it makes sense, since a page that looks fine in one browser can break in another.

I also liked seeing where HTML fits in the bigger course. It comes after topics like browsers, networking, and security, and before CSS, graphics, accessibility, and JavaScript. That tells me HTML is the starting point, and the later skills build on it: CSS for style, JavaScript for interactivity.

Overall, I think this lesson is a solid beginner introduction. My main takeaway is that good web pages come from planning, careful structure, and testing, not just writing code. I'd like to practice by building a simple page myself and checking it in more than one browser.
