My Understanding of Internet Communications

In this lesson, I learned how people communicate and share data over the Internet, and how to move text and binary files efficiently using popular services.

Voice over IP (VoIP)

A way to make voice calls by sending audio as digital data over the Internet instead of using traditional phone lines. Apps like Skype, Zoom, and WhatsApp calling work this way, and it's often cheaper than a regular phone service.

Web conferencing

Builds on VoIP by adding video, chat, and screen or content sharing. It lets people in different places hold meetings, classes, or webinars in real time.

Remote desktop software

Lets me see and control another computer from a distance. It's useful for IT support and for accessing a work computer from home.

File transfer and FTP

File transfer is the basic idea of moving files from one device to another. File Transfer Protocol (FTP) is a standard way to do this, where a client connects to a server to upload or download files. It works well for large files and for managing website content. Standard FTP isn't encrypted, so secure versions are better when the data is sensitive.

Peer-to-peer (P2P) file sharing

Sends files directly between users' computers rather than from one central server. This can be faster and more reliable for large files, but I need to be careful about copyright issues and malware.

SMS

The text messaging standard for mobile phones. It sends short messages over cellular networks and is commonly used for personal messages, alerts, and verification codes.

Overall

These tools fall into three groups:

  • Real-time voice and video: VoIP, web conferencing
  • Remote access: remote desktop
  • File sharing: FTP, P2P

Choosing the right one depends on speed, security, and convenience. Knowing how each works helps me communicate and share files more effectively and safely.
