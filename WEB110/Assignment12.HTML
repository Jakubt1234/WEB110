JavaScript Lesson Summary

Name:

In this lesson, I learned that JavaScript (JS) is a high-level, dynamic, weakly typed, prototype-based, multi-paradigm, interpreted programming language. The lesson introduces JavaScript and uses it to create and manipulate canvas graphics.

The lesson also covered the process of building a web document with scripting. First, I analysed the requirements by working out what dynamic functionality the document needs, which language is best suited to provide it, and what the document's overall requirements are. Next, I designed and produced the document, which meant planning the web page and its embedded scripts, writing simple HTML with accessibility in mind, and writing the embedded scripts themselves.

Finally, I learned to test the scripts and debug them, checking the document against the required functionality and repeating the process until it works correctly. The last step is completing the documentation and submitting it to the appropriate person for approval. The suggested readings were the Wikipedia articles on JavaScript, JavaScript syntax, and the canvas element.
