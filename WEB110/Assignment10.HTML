What I Learned: Internet Fundamentals, CSS

Cascading Style Sheets (CSS) is a style sheet language used to describe how a document written in a markup language, such as HTML, should be presented. Along with HTML and JavaScript, CSS is a cornerstone technology of the web. Most websites use it to create visually engaging webpages, and it also powers the user interfaces of web applications and many mobile applications.

In this lesson, I learned how to link cascading style sheets to web pages and how to create and use simple CSS pages. Linking is important because it lets one style sheet control the look of many pages, which keeps a website consistent and makes it easier to update.

I also learned how to format, style, and lay out the elements on a web page. This process begins with obtaining user requirements, so that the design meets the needs of the people who will use the site. From there, I learned to style the elements of a web page using CSS, such as text, colors, and spacing. I also learned how to apply CSS to multiple pages in a website, so that every page shares the same design. Finally, I practiced positioning document elements using CSS, which controls where things appear on the page.

The last major skill was testing and validating web pages. This includes testing the website in various browsers, since pages can look or behave differently depending on which browser is used. I also learned to validate CSS against industry standards, which helps make sure the code is correct and works reliably. After testing, I learned to report the test results to the appropriate person, such as a client, teammate, or supervisor, so any problems can be fixed.

Overall, this lesson showed me that CSS is what turns plain HTML into a polished, professional-looking website. It covers the full process, from understanding what users need, to styling and laying out a page, to checking that everything works properly before it is shared.
