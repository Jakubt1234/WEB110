In this lesson, I learned about Internet search engines and how they are used to find information on the World Wide Web. A search engine is a software system that searches through information available online and helps users find websites, documents, images, and other resources. I learned that it is important to use keywords when searching the internet. Choosing specific and appropriate keywords can help produce better and more useful search results. I also learned that searches may need to be refined if the original results do not provide the information I need. By changing or adding keywords, I can make my search more specific and find more relevant information. Another thing I learned is how to create search expressions based on the type of information I am looking for. This makes searching more effective and saves time. I also learned to review organizational guidelines when using the internet, especially when accessing it through a school or workspace. The lesson also taught me how to save useful search results. If I find an important webpage, I can create a bookmark or save a link so that I can easily find the information again later. I can also organize important information into bookmark folders. Overall, I learned that effectively using a search engine involves more than simply typing words into a search box. I need to choose good keywords, review the results, refine my search when necessary, and save useful information for future reference. These skills can help me find reliable and relevant information more quickly when completing chill assignments, researching topics, or looking for information online.
