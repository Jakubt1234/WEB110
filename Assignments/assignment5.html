Social media refers to computer-mediated technologies that allow people to create and share information, ideas, career interests, and other forms of expression through virtual communications and networks. This lesson introduced both the concept of social media and social networking as part of a broader Internet Fundamentals course. The core objectives covered several key areas. First, I learned to define essential social networking and web 2.0 concepts, which are foundational to understanding how the modern, interactive internet functions compared to the static “read-only” web of earlier years. Next, the lesson describes different types of social media tools and applications. This included explaining the defining characteristics of the term “social media,” identifying various categories of tools and platforms, and recognizing some of the issues associated with using social media, such as privacy concerns, misinformation, or overuse. I also learned how to compare different types of social media tools by selecting a specific category to review, researching the most popular tools and applications within it, listing the benefits of each, and ultimately determining the need or purpose. Finally, the lesson emphasized practical, hands-on skills: setting up and using popular social media tools. This involved identifying available tools for possible implementation, initiating the ones chosen, setting up the interface with text and file content, starting social networking interactions, and testing/evaluating the tools for ease of use. Overall, this lesson combined conceptual knowledge with applied skills, giving a well-rounded introduction to social media as part of internet literacy _ fitting within a larger curriculum that also covers web browsers, search engines, email, communications, networking, and security.
